# NimDaydu

NimDaydu 是一个 Chrome 扩展，把网页或选定桌面来源里的英文语音实时转成英文字幕，并翻译成中文。识别和翻译都在你自己的电脑上完成：不上传音频，不需要注册账号，也没有使用费。

适用于在 Chrome 里能播放声音的网页，例如 Discord 网页版、YouTube、Google Meet，以及 Zoom、Teams、Slack 的网页版。桌面客户端可从侧栏「更多 → 转录桌面声音」选择 Chrome 允许共享音频的来源。已有录音和视频也可以直接转录。

## 功能

- **侧栏字幕**：中英对照，每个英文短句下面紧跟着它的中文。可以回看、搜索、纠正术语或复制字幕，支持 TXT、JSON、SRT 和 Markdown 导出。
- **网页悬浮字幕**：半透明的字幕框叠在网页上，网页全屏时会自动出现。底部一行是边说边出的英文，上面是已经说完的句子；每句的中文译好后，会填到这句英文的上方。
- **中文早译**：一句话说完，或长句的前半句已经稳定时，本机模型可以先显示浅色中文。英文定稿后，文字一致就沿用译文。
- **自动保存**：每次字幕自动保存到项目里的 `OUTPUTS` 文件夹，只保存文字，不保存音频。
- **完全本机运行**：英文识别使用 Moonshine 和 Parakeet，中文翻译使用腾讯 Hy-MT2，三个模型都运行在你的电脑上。

## 系统要求

| | Windows | Mac | Linux |
|---|---|---|---|
| 系统 | Windows 10 或 11（64 位） | Apple 芯片（M1 及以后），macOS 15 或更新版本 | x86-64 Ubuntu 24.04 |
| 内存 | 推荐 16 GB | 推荐 16 GB | 推荐 16 GB |
| 磁盘空间 | 约 4 GB | 约 4 GB | 约 4 GB |
| 浏览器 | Chrome 142 或更新版本 | Chrome 142 或更新版本 | Chrome 142 或更新版本 |

识别在 CPU 上运行。翻译优先使用显卡：Windows 上通过 Vulkan，支持 Intel、AMD、NVIDIA 显卡；Mac 上通过 Metal。没有可用显卡时，翻译自动改用 CPU。

## 安装

按系统安装：

- **Windows**：见 [docs/windows.md](docs/windows.md)
- **Mac**：见 [docs/mac.md](docs/mac.md)
- **Ubuntu x86-64**：在 Linux 文件系统内的项目目录运行 `bash setup.sh`，再运行 `bash start.sh`。打开 `chrome://extensions`，开启开发者模式，加载 `extension/.output/chrome-mv3`。结束时运行 `bash stop.sh`。

导入音视频文件需要能在终端运行 `ffmpeg`。实时字幕由浏览器直接采音。

安装只需要做一次。安装脚本会把依赖和模型都放在项目文件夹里，不影响电脑上的其他软件。

## 日常使用

1. **启动本机服务**：Windows 双击 `Start-NimDaydu.cmd`，Mac 双击 `Start-NimDaydu.command`。看到“已就绪”就可以了。
2. **打开字幕**：在有英文声音的网页上，点击浏览器工具栏里的 NimDaydu 图标打开侧栏，然后点 **开始**。也可以用快捷键打开侧栏：Windows 是 Alt + Shift + N，Mac 是 Option + Shift + N。
3. **悬浮字幕**：网页全屏时会自动出现。随时显示或隐藏它：点侧栏顶部的字幕按钮，或按 Alt + Shift + O（Mac 是 Option + Shift + O）。想让它在普通窗口里也一直显示，在设置里把“网页悬浮字幕”改成“一直显示”。
   - 拖动字幕框可以移动位置，双击回到底部；拖动顶部的小横条可以调高度。默认大约显示 3 句，加上底部一行实时英文。
   - 鼠标移上去会出现 A− / A+ 调整字号，× 暂时隐藏。
   - 用滚轮往上翻可以回看前面的句子，翻回最底部后会继续自动滚动。
   - 在设置中可以开启鼠标点穿和静默收起；有人继续讲话时字幕会回来。
   - 设置为“只看中文”时，悬浮字幕也只显示已经译好的中文。
4. **录音、历史与独立字幕窗**：点「更多 → 历史记录与文件转录」。选择本地音视频即可按文件速度生成双语字幕，点击时间可回听。桌面通话时可在此打开实时置顶字幕。首次使用可以先在侧栏点「试听英语样本」。
5. **结束**：在侧栏点 **结束**，等最后一句中文出来。不用时再运行停止脚本释放内存：Windows 双击 `Stop-NimDaydu.cmd`，Mac 双击 `Stop-NimDaydu.command`。

只要侧栏或悬浮字幕有一个开着，字幕就会继续。两个都关闭约 10 秒后，采集会自动停止。

短时间内反复使用时，保留本机服务，只在侧栏点“开始”和“结束”，模型就不用重新加载。停止脚本会完全退出服务并释放模型内存。

## 工作原理

NimDaydu 由两部分组成：Chrome 扩展负责采集标签页的声音和显示字幕，本机服务负责识别和翻译。两者只通过 `127.0.0.1` 通信。

![架构图：Chrome 里的采音页把标签页声音送到本机服务；Moonshine 出实时英文，Parakeet 复核定稿，切成短句后回到采音页，再分发到侧栏和悬浮字幕；英文交给 HY-MT 翻译，中英文都保存到 OUTPUTS](docs/images/architecture.png)

- **采音页**是扩展在后台打开的一个隐藏页面。它保留标签页原声播放，同时用同一个音频时钟输出 16 kHz 单声道、排队翻译，再把字幕发给侧栏和悬浮字幕，所以关掉侧栏后悬浮字幕仍然能继续。
- **Moonshine Small** 边听边出英文，大约每 0.5 秒更新一次。
- **Parakeet TDT** 连续读取原音，保留切分点前后的声音，按识别出的词和时间定稿。
- **Hy-MT2-1.8B** 负责翻译。它通过 llama.cpp 运行，Windows 上用 Vulkan、Mac 上用 Metal 调用显卡；开启双语后在后台加载。关闭翻译时只需启动识别模型。

## 字幕是怎么出现的

![时序图：实时英文、浅色早译和整句复核如何接续；图中时间取自 v0.7 的会议录音测试](docs/images/sequence.png)

- 英文边说边显示在侧栏和悬浮字幕的最下面，听到更多内容后可能会修正。说的过程中就已经按句子分好行，句子定稿后会留在原来的位置。
- 一个短句说完后，NimDaydu 会用更准确的模型把这段音频重新识别一遍，确定英文，然后翻译成中文。
- 服务在短暂停顿处或连续讲话达到时限时切分。前后相邻的复核片段都能听到边界处的原音。说到下一个从句时，如果前半句的英文连续两次识别都一致，翻译模型空闲就先翻这半句。
- 早译的中文以浅色显示。复核后英文相同就沿用这句中文；数字、疑问语气或技术名词有变化时会重新翻译，例如把 `C++` 改成 `C#`。
- 定稿的中文译好之前，这句英文上方会显示“…”占位，译好后直接填进去，下面的内容不会被挤动。手动纠正英文术语后会重新翻译受影响的句子。翻译偶尔失败时会自动重试；仍然失败时，侧栏会出现“恢复翻译”按钮。

多人同时说话、口音重或背景噪声大时，英文可能识别错，中文也会跟着错，而且错得很通顺。重要内容请对照英文。

## 设置

点侧栏右上角的齿轮打开设置页。更改会自动保存。

| 项目 | 默认 | 说明 |
|---|---|---|
| 翻译方式 | 本机模型 Hy-MT2-1.8B Q4 | 使用本机模型，也可以关闭翻译，只显示英文 |
| 显示内容 | 中文和英文 | 也可以只看中文或只看英文 |
| 文字大小 | 18 px | 同时影响侧栏和悬浮字幕 |
| 网页悬浮字幕 | 全屏时自动显示 | 也可以设为一直显示或关闭 |
| 出字速度 | 更快 | “更完整”会多等一会儿，把同一句话合在一起翻译 |
| 识别方式 | 实时 + 原音复核 | 想省电可以只用实时识别，但准确度会下降 |
| 自动保存 | 开启 | 保存位置是项目里的 `OUTPUTS` 文件夹 |

`glossary.json` 用来固定品牌名称的写法，例如 `discord → Discord`，避免被译成“不和”。修改后重启本机服务即可生效。

## 保存与导出

- 自动保存的字幕按日期存放，例如 `OUTPUTS/2026-10-28/20261028-214651_youtube_<会话ID>/`。
- 每个文件夹里有两个文件：`transcript.txt` 方便阅读，`session.json` 包含时间、英文和中文。
- 侧栏里的「纠词」支持只改这句、改本场或长期记住，也可以撤销。搜索可以按识别原词或纠正后的拼写匹配。
- 「更多」可以复制字幕、导出 TXT / JSON / SRT / Markdown、打开历史记录。清空侧栏不会删除已经保存的文件。
- 外部程序可在会中重复读取同一个 `session.json`。用会话 ID 和字幕 ID 识别同一句，按 `revision` 接收修正，`translationRevision` 与它相同时中文对应当前原文。
- 只保存定稿的文字，不保存音频和实时草稿。如果电脑突然断电，最后几秒可能来不及保存。

## 隐私

- 实时采集的音频只在内存中处理。导入文件时服务暂存一份选中的文件，在转录结束或中止时移除。
- 本机服务只接受 `127.0.0.1` 的连接，并且只把连接令牌交给已安装的 NimDaydu 扩展。
- 字幕翻译在本机完成，文字不会发送到外部服务。
- 网页模式只采集选定标签页；桌面模式采集 Chrome 选择器中主动共享的音源。共享整个系统音频时其他应用的声音也会进入字幕。
- 在会议中使用时，请按照所在场合的要求告知其他参与者。

## 限制

- 桌面来源能否共享音频取决于系统和 Chrome。选择器没有音频选项时，可使用网页版标签页。
- 只支持把英文翻译成中文。
- 不区分说话人。
- 部分受版权保护的媒体，或者公司管理的浏览器，可能不允许采集声音。

## 常见问题

| 情况 | 处理 |
|---|---|
| 侧栏显示“本机服务未连接” | 先运行启动脚本（Windows：`Start-NimDaydu.cmd`，Mac：`Start-NimDaydu.command`），然后在侧栏点“重新连接” |
| “开始”按钮是灰的 | 在有声音的网页上点一次工具栏里的 NimDaydu 图标 |
| 全屏后看不到悬浮字幕 | 确认设置里的“网页悬浮字幕”不是“关闭”，或者按 Alt + Shift + O |
| 快捷键没反应 | 打开 `chrome://extensions/shortcuts` 查看或修改快捷键 |
| 网页刷新后悬浮字幕不见了 | 在这个网页上按 Alt + Shift + O（Mac 是 Option + Shift + O） |
| 提示本机翻译模型未就绪 | 重新运行安装脚本并重启本机服务；详细日志在 `.nimdaydu/translator.log` |
| 提示“正在追赶” | 电脑暂时忙不过来。音频不会丢，通常几秒后自动恢复 |
| 提示“语音识别持续积压” | 关闭其他占用 CPU 很多的程序，然后重新开始 |
